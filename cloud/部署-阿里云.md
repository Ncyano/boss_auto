# 阿里云 ECS 部署（Ubuntu 22.04 / 2核2G / 40G ESSD / 200M 峰值）

## 一、开服前准备（阿里云控制台）

### 1. 实例

| 项目 | 值 |
|---|---|
| 规格 | 2 核 2G（经济型 e 或 u1）|
| 镜像 | **Ubuntu 22.04 LTS 64 位** |
| 系统盘 | ESSD 40 GB |
| 带宽 | 按使用流量，峰值 200 Mbps |
| 地域 | **华东1（杭州）**（与百炼同区域，API 延迟最低）|

### 2. 安全组（入方向）

| 端口 | 用途 | 来源建议 |
|---|---|---|
| 22 | SSH 管理 | **只填你的办公 IP** |
| 8000 | 云端服务 | 只填办公 IP 段 |
| 443 | 若配 HTTPS | 0.0.0.0/0 |

> 不要对公网全开 8000，人事通过固定 IP 或 VPN 访问更安全。

### 3. 拿到服务器后先做

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 装 Docker
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER && newgrp docker

# 装 compose 插件
sudo apt install -y docker-compose-plugin
```

## 二、上传代码

在**本地**（Windows）打包再上传：

```powershell
# 本地执行：只打包云端需要的部分
Compress-Archive -Path cloud, boss_vision, data, "运营助理知识库_v0.1", config.example.json `
  -DestinationPath boss-cloud.zip -Force
scp boss-cloud.zip root@<ECS公网IP>:/opt/boss/
```

或者直接在服务器上 `git clone` 你的仓库（更推荐，后面更新方便）。

## 三、目录结构（服务器上）

```
/opt/boss/
├── cloud/
│   ├── server.py
│   ├── static/index.html
│   ├── requirements-cloud.txt
│   └── data/                 ← 结果与任务（持久化）
├── boss_vision/              ← 复用 vlm / judge / screening / kb
├── 运营助理知识库_v0.1/
├── data/                     ← 学校名单、screening-rules.json
└── config.json               ← 填两个 API key
```

## 四、配置 API key

```bash
cd /opt/boss
cp config.example.json config.json
nano config.json
```

填：

```json
"vision": { "api_key": "sk-…（通义，视觉识别）", "pipeline": "vision" },
"judge":  { "api_key": "sk-…（DeepSeek，判定）" }
```

## 五、启动服务

### 方式 A：直接跑（先验证）

```bash
cd /opt/boss
python3 -m venv .venv
./.venv/bin/pip install -r cloud/requirements-cloud.txt

export BOSS_TOKEN="<自定义口令>"
./.venv/bin/python -m uvicorn cloud.server:app --host 0.0.0.0 --port 8000
```

浏览器打开 `http://<ECS公网IP>:8000` 看到看板即成功。

### 方式 B：Docker（推荐长期）

```bash
cd /opt/boss
cat > Dockerfile <<'EOF'
FROM python:3.12-slim
WORKDIR /app
RUN apt-get update && apt-get install -y --no-install-recommends libgl1 libglib2.0-0 \
    && rm -rf /var/lib/apt/lists/*
COPY cloud/requirements-cloud.txt /tmp/
RUN pip install --no-cache-dir -r /tmp/requirements-cloud.txt
COPY . /app
ENV BOSS_TOKEN=change-me
EXPOSE 8000
CMD ["python","-m","uvicorn","cloud.server:app","--host","0.0.0.0","--port","8000"]
EOF

docker build -t boss-cloud .
docker run -d --name boss-cloud --restart unless-stopped \
  -p 8000:8000 -e BOSS_TOKEN="<自定义口令>" -v /opt/boss/cloud/data:/app/cloud/data boss-cloud
```

## 六、人事电脑接入

1. 下发代理（约 8~60MB，视是否带 numpy/cv2）
2. 人事双击启动，填：
   ```
   云端地址：ws://<ECS公网IP>:8000/agent
   口令：<BOSS_TOKEN>
   ```
3. 本地浏览器登录 BOSS，停在「推荐牛人」
4. 云端看板点「开始」

## 七、资源占用预期（2核2G）

| 项目 | 占用 |
|---|---|
| uvicorn + FastAPI | 约 120 MB 内存 |
| 每任务并发截图缓冲 | 约 5 MB（用完即丢）|
| 结果文件 | 约 1 KB/人 → 800 人 800 KB |
| CPU | 峰值 <20%（大部分时间等 API）|

**结论：2核2G 完全够，瓶颈在网络与百炼 API 延迟。**

## 八、每日维护

## 九、开机自启

Docker 的 `--restart unless-stopped` 已保证；若用方式 A，加 systemd：

```bash
sudo tee /etc/systemd/system/boss-cloud.service <<'EOF'
[Unit]
Description=BOSS cloud
After=network.target

[Service]
WorkingDirectory=/opt/boss
Environment=BOSS_TOKEN=<自定义口令>
ExecStart=/opt/boss/.venv/bin/python -m uvicorn cloud.server:app --host 0.0.0.0 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
EOF
sudo systemctl enable --now boss-cloud
```

## 十、排障

| 现象 | 原因 | 处理 |
|---|---|---|
| 看板打不开 | 安全组没放行 8000 | 阿里云控制台加规则 |
| 显示「已连接代理：0」| 代理没连或口令错 | 检查代理窗口状态灯 |
| 任务状态 error: 没有已连接代理 | 同上 | 先启动代理 |
| 识别全空 | config.json key 错/欠费 | 服务器上跑 `python -c` 测试 key |
| 点击位置偏 | 浏览器缩放不是 100% | 代理会回报 ratio，云端自动换算；若仍偏，锁定浏览器缩放 |
